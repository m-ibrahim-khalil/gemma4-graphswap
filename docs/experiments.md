## Decision rules (frozen in docs/preregistration.md)

- Primary metric: resolution rate on the task set, paired per task against C1 at the same seed.
- Noise floor: C1/1234 vs C1/4321 disagreement count. An effect is reported as "beyond noise" only when the pooled McNemar exact p < 0.05 **and** |wins − losses| exceeds the noise-floor discordant count.
- Phase B picks the two conditions with the largest pooled |diff| vs C1; if none exceeds the noise floor, Phase B runs C0 and C3 (the two extremes).
- No run is discarded. Crashed runs are rerun with the same seed and both manifests are kept.

## Secondary metrics (from traces)

graph-tool calls per task; graph-tool error responses; analyzer calls; gold file read; gold file edited; wall seconds; prompt and completion tokens; `patch_submitted`.
